# 收据打印功能设计文档

**日期**: 2026-05-21  
**版本**: 1.0  
**状态**: 待审核

## 1. 概述

### 1.1 目标

为 POS 系统添加完整的收据打印功能，支持多种打印机硬件，提供可靠的打印体验和完善的错误处理机制。

### 1.2 核心需求

- 支持蓝牙、USB、网络三种打印机连接方式
- 生成标准 ESC/POS 格式的收据
- 打印失败时提供重试、跳过、保存队列三种选项
- 支持打印队列和历史记录管理
- 提供打印机设置和管理界面
- 支持多份打印和自动打印配置

### 1.3 技术选型

**Flutter 插件**:
- `flutter_blue_plus: ^1.31.0` - 蓝牙连接（已有）
- `esc_pos_utils: ^1.1.0` - ESC/POS 指令生成（已有）
- `esc_pos_bluetooth: ^0.4.1` - 蓝牙打印机
- `network_info_plus: ^5.0.0` - 网络打印机发现
- `usb_serial: ^0.5.0` - USB 打印机（桌面版）

## 2. 系统架构

### 2.1 核心组件

```
PrinterService (统一接口)
    ├── BluetoothPrinterManager (蓝牙打印机)
    ├── UsbPrinterManager (USB 打印机)
    ├── NetworkPrinterManager (网络打印机)
    ├── EscPosGenerator (ESC/POS 指令生成)
    └── PrintQueueService (打印队列管理)
```

### 2.2 数据模型

**PrinterConfig (打印机配置)**
```dart
class PrinterConfig {
  String id;
  String name;
  PrinterType type; // bluetooth, usb, network
  String address; // MAC address / IP address / USB path
  int paperWidth; // 58mm or 80mm
  bool isDefault;
  DateTime? lastConnected;
}
```

**PrintJob (打印任务)**
```dart
class PrintJob {
  String id;
  String transactionId;
  String transactionNumber;
  DateTime createdAt;
  PrintJobStatus status; // pending, printing, success, failed
  int retryCount;
  String? errorMessage;
  Map<String, dynamic> receiptData;
}
```

**PrinterStatus (打印机状态)**
```dart
enum PrinterStatus {
  disconnected,
  connecting,
  connected,
  printing,
  error
}
```

## 4. 核心功能设计

### 4.1 打印机连接管理

**蓝牙打印机连接流程：**

1. 扫描附近的蓝牙设备
2. 过滤出打印机设备（根据设备名称特征）
3. 用户选择打印机
4. 配对并连接
5. 保存配置到数据库
6. 测试打印

**USB 打印机连接流程：**

1. 检测 USB 设备列表
2. 识别打印机设备（VID/PID）
3. 打开串口连接
4. 保存配置
5. 测试打印

**网络打印机连接流程：**

1. 扫描局域网内的打印机（端口 9100）
2. 或手动输入 IP 地址和端口
3. 测试 TCP 连接
4. 保存配置
5. 测试打印

### 4.2 收据打印流程

**正常流程：**

```
1. 支付成功 → 显示支付成功对话框
2. 用户点击"打印收据"
3. 检查是否有默认打印机
   - 没有 → 提示"请先设置打印机"
   - 有 → 继续
4. 检查打印机连接状态
   - 未连接 → 尝试自动连接
   - 连接失败 → 显示错误对话框
5. 生成 ESC/POS 打印数据
6. 发送到打印机
7. 等待打印完成（超时 10 秒）
8. 成功 → 记录到打印历史
9. 关闭对话框
```

**错误处理流程：**

```
打印失败 → 显示错误对话框
  ├─ 重试 → 重新执行打印流程
  ├─ 跳过 → 关闭对话框，不保存
  └─ 保存到队列 → 添加到 print_queue 表
```

### 4.3 打印队列管理

**自动重试机制：**

- 后台服务每 30 秒检查一次队列
- 获取状态为 'pending' 或 'failed' 的任务
- 检查重试次数（最多 3 次）
- 检查打印机连接状态
- 尝试打印
- 更新任务状态

**手动重新打印：**

- 用户在"打印历史"界面选择交易
- 点击"重新打印"
- 从历史数据重新生成收据
- 执行打印流程

### 4.4 ESC/POS 指令生成

**收据内容结构：**

```
┌─────────────────────────────┐
│      [LOGO/店铺名称]         │
│    Malaysia E-Invoice       │
├─────────────────────────────┤
│ 收据号: TXN-20260521-0001   │
│ 日期: 21/05/2026 14:30      │
│ 收银员: John                │
│ 客户: [可选]                │
├─────────────────────────────┤
│ 商品          数量    金额   │
├─────────────────────────────┤
│ 商品A          2x   RM 20.00│
│   备注: 无糖                │
│ 商品B          1x   RM 15.00│
├─────────────────────────────┤
│ 小计:              RM 35.00 │
│ 折扣 (10%):       -RM  3.50 │
│ 税额 (6%):         RM  1.89 │
├─────────────────────────────┤
│ 总计:              RM 33.39 │
├─────────────────────────────┤
│ 支付方式: 现金              │
│ 收款:              RM 50.00 │
│ 找零:              RM 16.61 │
├─────────────────────────────┤
│       谢谢惠顾！            │
│      欢迎再次光临           │
└─────────────────────────────┘
```

**ESC/POS 指令序列：**

1. 初始化打印机 (ESC @)
2. 设置字符集为 UTF-8
3. 居中对齐 + 加粗 → 打印店铺名称
4. 居中对齐 → 打印副标题
5. 打印分隔线
6. 左对齐 → 打印交易信息
7. 打印分隔线
8. 打印商品列表（循环）
9. 打印分隔线
10. 打印汇总信息
11. 打印支付信息
12. 打印分隔线
13. 居中对齐 → 打印感谢语
14. 走纸 + 切纸 (GS V)

## 6. 错误处理详细设计

### 6.1 错误类型和处理策略

**连接错误：**

| 错误 | 原因 | 处理方式 |
|------|------|----------|
| 蓝牙未开启 | 设备蓝牙关闭 | 提示开启蓝牙，提供跳转到设置 |
| 蓝牙权限被拒绝 | 未授予蓝牙权限 | 提示授予权限，引导到应用设置 |
| 打印机未找到 | 打印机关机或超出范围 | 提示检查打印机，提供重试 |
| 配对失败 | 配对码错误或拒绝 | 提示重新配对 |
| 连接超时 | 网络问题或打印机忙 | 自动重试 3 次，失败后提示 |

**打印错误：**

| 错误 | 原因 | 处理方式 |
|------|------|----------|
| 打印机缺纸 | 纸张用完 | 提示添加纸张，提供重试 |
| 打印机忙碌 | 正在处理其他任务 | 等待 2 秒后自动重试 |
| 打印机过热 | 连续打印过多 | 提示等待冷却，延迟重试 |
| 数据传输失败 | 连接中断 | 重新连接后重试 |
| 未知错误 | 其他硬件问题 | 记录日志，提示联系技术支持 |

### 6.2 重试策略

**自动重试（后台队列）：**

```dart
重试间隔: 指数退避
- 第 1 次: 立即
- 第 2 次: 30 秒后
- 第 3 次: 2 分钟后
- 第 4 次: 5 分钟后
- 超过 4 次: 标记为失败，需要手动处理
```

**手动重试（用户触发）：**

- 立即执行，不受重试次数限制
- 失败后仍可继续重试

### 6.3 日志记录

**记录内容：**

- 时间戳
- 操作类型（连接/打印/断开）
- 打印机信息（类型、地址）
- 交易信息（交易号、金额）
- 结果（成功/失败）
- 错误信息（如果失败）
- 重试次数

**日志存储：**

- 本地文件：`logs/printer_YYYYMMDD.log`
- 保留 30 天
- 超过 10MB 自动轮转

## 7. 性能优化

### 7.1 连接优化

**连接池管理：**

- 保持默认打印机的连接（如果支持）
- 空闲 5 分钟后自动断开（节省电量）
- 打印前自动检查连接状态
- 连接失败时自动重连（最多 3 次）

### 7.2 打印优化

**数据预处理：**

- 提前生成 ESC/POS 指令（支付成功时）
- 缓存常用的打印模板
- 压缩重复的指令序列

**批量打印：**

- 支持一次打印多份（配置项）
- 使用队列避免并发冲突
- 打印间隔 500ms（避免打印机过热）

### 7.3 内存优化

**打印队列限制：**

- 最多保留 100 条待打印任务
- 超过限制时删除最旧的已完成任务
- 失败任务优先保留

**历史记录清理：**

- 自动删除 90 天前的打印历史
- 保留失败记录（便于排查问题）

## 10. 风险和挑战

### 10.1 技术风险

**硬件兼容性：**

- **风险**: 不同品牌打印机的指令集可能有差异
- **缓解**: 使用标准 ESC/POS 指令，提供兼容性列表，充分测试

**蓝牙连接稳定性：**

- **风险**: 蓝牙连接可能不稳定，导致打印失败
- **缓解**: 实现自动重连机制，提供有线连接选项

**平台差异：**

- **风险**: Android/iOS/Windows 的蓝牙和 USB API 不同
- **缓解**: 使用跨平台插件，针对不同平台做适配

### 10.2 用户体验风险

**打印速度：**

- **风险**: 打印速度慢影响收银效率
- **缓解**: 优化数据传输，支持异步打印

**错误提示：**

- **风险**: 错误信息不清晰，用户不知道如何处理
- **缓解**: 提供详细的错误说明和解决建议
